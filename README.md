## 4. 팀 커뮤니케이션

### **4.1 커뮤니케이션 규칙**
- 매일 **오전 9시** 데일리 스크럼 진행
    - **어제 한 일**, **오늘 할 일**, **프로젝트 현황** 등을 공유하며 진행 상황 점검.
- **Git flow 전략**으로 브랜치 관리, **PR**을 통한 이슈 관리
- 문서 공유 및 회의 기록은 **Notion**을 통해 관리.
- **Jira를 통한 스크럼 기반 일정 관리**
